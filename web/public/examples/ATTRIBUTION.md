# LeFood-Set v1 example-image attribution

The 20 JPEG files in this directory are ten before/after pairs copied from
**LeFood-Set v1** by Yuita Arum Sari, Yudi Arimba Wani, and Atsushi Nakazawa, DOI
[`10.17632/cchsk79jkt.1`](https://doi.org/10.17632/cchsk79jkt.1).

- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- Source identifiers: `lefood-0142`, `lefood-0192`, `lefood-0226`,
  `lefood-0320`, `lefood-0400`, `lefood-0441`, `lefood-0461`,
  `lefood-0489`, `lefood-0507`, and `lefood-0530`
- Changes: file contents are unmodified; files were renamed to the stable
  `<source-id>-<before|after>.jpg` convention for the benchmark explorer.
- Selection: five examples are deliberately selected near-correct predictions
  spanning the target range; five are the largest paired-model errors. This is
  not a random or representative sample of the full dataset.
