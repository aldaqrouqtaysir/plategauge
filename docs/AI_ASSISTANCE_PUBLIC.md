# Public AI-assistance disclosure

PlateGauge was developed through a substantially AI-assisted workflow. This
summary is the release-facing disclosure; the more detailed internal workflow
log is not part of the prospective public repository.

## Work performed with AI assistance

AI systems supported:

- source, problem, and prior-art research;
- project comparison, architecture, protocol, model, and evaluation planning;
- data-audit and duplicate-analysis tooling;
- implementation of the Python training/evaluation system and React/TypeScript
  explorer;
- experiment execution, statistical analysis, ONNX export, robustness/error
  analysis, testing, security checks, documentation, and packaging; and
- drafting of demonstration, documentation, and governance materials.

All released numerical claims are tied to machine-readable evidence and frozen
identities. AI-generated visual interpretations were kept separate from source
labels and did not alter the confirmatory dataset or results.

## Claims deliberately withheld

This record does not claim that the named human contributor independently wrote
every line, personally executed every automated step, completed an independent
frozen-path reproduction, conducted user testing, deployed a public service, or
achieved operational food-waste impact. Those claims require separate evidence
and must never be inferred from the existence of the repository.

At the 20 September 2026 source freeze, independent reproduction, contribution
wording review, release authorization, release tagging, deployment, and live
public smoke remained pending.
