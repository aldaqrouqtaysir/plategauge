# Checkpoints

Milestone snapshots belong here only after their source commit and artifact
hashes are known. Do not manually copy raw data, model caches, credentials, or
unlicensed images into a snapshot.

Each checkpoint record should include:

- milestone name and UTC timestamp;
- Git commit and dirty-state declaration;
- included artifact list and SHA-256 hashes;
- dataset/model identifiers without raw source data;
- passed/failed gate and unresolved blockers;
- exact restore/reproduction commands; and
- whether required human review occurred.
